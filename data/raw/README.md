# Raw data

These files are not committed (size and licenses). Download them and save them here
under these names:

| File | Source | Used for |
|---|---|---|
| `mendeley_dga_2025.zip` | Gregório & Cansian, "Legitimate domains and DGA categorized morphologically and by families", Mendeley Data v1, 2025, CC BY 4.0: https://data.mendeley.com/datasets/nhvyvytn2h/1 | DGA domains (160 families) |
| `kaggle_dga_2021.zip` | C. Givre, "DGA dataset", Kaggle v1, 2021: https://www.kaggle.com/datasets/gtkcyber/dga-dataset | DGA domains (7 family labels) |
| `tranco_64VVX_top1m.zip` | Tranco top 1M, list 64VVX (17 Sep to 16 Oct 2026): https://tranco-list.eu/list/64VVX | legitimate domains |

Only the DGA rows of the Mendeley and Kaggle files are used; all legitimate domains
come from Tranco.
